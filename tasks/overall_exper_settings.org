* Experimental Plan of Mobius Injection

** 已选取clawbench作为evaluation benchmark
** 需要搭建一个能够进行DoS攻击的环境。
+ 使用ollama来作为DoS攻击的测试（如支持多少并发等）。
+ 在现有的LLM API上做测试，证明这种注入可以被触发
+ 使用ollama来做DoS触发数的测试
+ 需要考虑到不同的Agent工具/系统
+ 对构建 evaluation benchmark的思考
  + 需要有一个比较复杂的任务，该任务的中间过程中可以被插入这些恶意的代码
  + 对应的task个数不能太少，太少则不具有可分析性
+ 考虑防御
  + 现有的LLM API Server DoS Attack
  + 现有的在Agent上面的安全控制/版本控制
  + 现有的LLM agent系统上的防御与权限控制
  + 现有的marketplace上相关防御的skills

      + 在不同的淹没比（即injected text占完整text的比例）下的injection成功率
  + Effectiveness of DDoS Attacks：探究DDoS如果实现拒绝服务的话需要多少资源
